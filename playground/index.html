Blocker
A citation is not an exact span of the contract, or the review cites nothing. Any blocker rejects the review, whatever its other scores.
Review
A requirement of the release policy is unmet: a missed or unexpected clause, a missed or extra risk, a wrong severity, or a duplicate flag. A qualified reviewer decides.
Pass
The item matches the answer set. A review with no blockers and no review items is pilot eligible, which still requires a lawyer to confirm every flag and citation.

  
What the scores rest on
This page runs {{WHEEL}}, the same package as the command line, inside your browser. The exported JSON is the result contract-eval score writes for the same file and case. The answer sets were written by hand for three synthetic contracts and record whose side each severity is judged from. A score measures agreement with that answer set; it is not a public benchmark result. Read the metric reference ↗
