A grading machine for AI contract reviews. An AI model reads a contract and writes a review. The harness compares that review with an answer key written by a lawyer, then prints a scorecard.

The idea

An exam with an answer key

Think of a teacher marking an exam. The harness needs the same four things, and each one is a file in the repository. It ships three practice contracts: a non-disclosure agreement (NDA), a software subscription (SaaS) agreement and a data processing agreement (DPA).

What it grades

Three questions about every review

Did it find the clauses?

A contract is made of sections such as term, governing law or assignment. The harness counts what the AI found.

Recall
Of the clauses that exist, how many did it find?
Precision
Of the clauses it listed, how many actually exist?
F1
One number that combines the two.

Did it judge the risks right?

Finding a clause is the easy part. A good reviewer knows that a confidentiality duty with no end date is a serious problem, while a clause about how notices are sent is minor.

The harness checks which clauses the AI flagged as risky, and whether each severity (low, medium or high) matches the answer key.

Are the quotes real?

Every risk must be backed by a quote from the contract. AI models sometimes invent quotes that sound right but appear nowhere in the document.

The harness looks for each quote word for word, ignoring only capitals, punctuation and spacing. One invented quote means an automatic REJECT. In legal work a fake citation disqualifies the whole review.

    Try it

    Run it on your own machine

    You need uv, which fetches a suitable Python for you. No API key is needed.

    Grade the bundled NDA review and write scorecard.md 
    git clone https://github.com/sebastianfoerste/contract-review-eval-harness
cd contract-review-eval-harness
uv sync
uv run python -m contract_eval evaluate --case nda
    Grade your own tool's review, saved as JSON in the review format 
    uv run contract-eval score my-review.json --case nda

    The second command exits with an error on a REJECT. A team can run it in their automated tests and block any change that makes their AI's reviews worse. To try it with nothing installed, use the browser playground.

    Design choices

    Ground rules

    Offline and repeatable
    By default nothing goes over the internet and no API key is needed. The same review always gets the same score.
    Synthetic contracts only
    Every contract is made up. Real agreements and client data never go into the repository.
    A lawyer writes the answers
    Answer keys are written by hand and never generated by code. Every flagged risk and quote still needs a qualified lawyer before anyone relies on it.
    Flawed on purpose
    The bundled review contains planted mistakes. That proves the grader catches errors instead of handing out full marks.

    Later
